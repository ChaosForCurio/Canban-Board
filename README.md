# Canban-Board
 
##  Project Description


A Kanban Board is a visual project management tool designed to help teams and individuals visualize their work, limit work-in-progress, and maximize efficiency (or "flow"). Originally developed by Toyota for manufacturing, it is now the gold standard for software development, marketing, and personal productivity.How It WorksThe board uses a system of Cards and Columns to move a project from "Start" to "Finish" in a transparent way.
